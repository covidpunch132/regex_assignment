# 정규표현식 과제

파이썬 정규표현식을 사용해서 대동제 및 해커톤 로그 파일에서 필요한 정보를 추출하는 프로그램입니다.

## 기능
- 이메일 주소 추출 (잘못된 형식 제외)
- 010으로 시작하는 휴대전화 번호 추출
- 학번과 학과 추출
- GitHub 주소와 2026년 쿠폰 코드 추출
- 부스별 매출액 추출 및 총합 계산

## 실행 방법
`main.py`와 `data.txt`를 같은 폴더에 넣고 실행하면 됩니다.

```bash
python main.py
```

별도의 라이브러리 설치는 필요하지 않습니다.

- 학번/학과 3개
