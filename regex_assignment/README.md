# 정규표현식 통합과제: 대동제 및 해커톤 운영 로그 분석

## 프로젝트 소개
Python의 `re` 모듈을 이용하여 대학 축제 및 해커톤 운영 로그에서 이메일, 휴대전화, 학번/학과, GitHub URL, 쿠폰 코드 및 부스 매출액을 추출하는 프로그램입니다.

## 파일 구성
- `main.py`: 정규표현식 데이터 분석 프로그램
- `data.txt`: 분석 대상 원본 로그 파일
- `README.md`: 실행 방법, 사용된 정규표현식 및 결과 안내

## 실행 방법
1. Python 3.8 이상을 설치합니다.
2. 세 파일을 동일한 폴더에 둡니다.
3. 터미널에서 `python main.py`를 실행합니다. (Windows에서는 `py main.py`도 가능합니다.)

외부 라이브러리 설치는 필요하지 않습니다.

## 구현 기능 및 정규표현식

### 1. 유효한 이메일 추출
```regex
(?<![\w.@+-])[A-Za-z0-9._%+-]+@[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)+(?![\w.-])
```
`아이디@도메인.상위도메인` 형식에 해당하는 이메일을 찾습니다. `hyunwoo@.ac.kr`은 도메인 시작 문자가 잘못되어 제외합니다.

### 2. 휴대전화 번호 추출
```regex
(?<!\d)010[-. ]\d{4}[-. ]\d{4}(?!\d)
```
`010`으로 시작하고 그 뒤가 4자리-4자리인 전화번호를 찾습니다. `-`, `.`, 공백 구분자를 허용합니다. `010-123-4567`, `063-3290-1114`는 제외합니다.

### 3. 202로 시작하는 9자리 학번과 학과 추출
```regex
\[(202\d{6})\s*/\s*([^\]\n/]+?)\s*\]
```
대괄호 안에서 학번과 학과를 함께 찾아 두 개의 그룹으로 분리합니다. 외부인 학번 `999900000` 및 8자리 `20261122`는 제외합니다.

### 4. GitHub URL과 2026년도 쿠폰 추출
```regex
https?://github\.com/[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+
```
`github.com` 저장소 주소만 찾고 `gitlab.com`은 제외합니다.

```regex
\bFEST-2026-[A-Za-z0-9]+\b
```
`FEST-2026-`으로 시작하는 코드만 찾고 `FEST-2025-OLD9`는 제외합니다.

### 5. 부스별 매출액과 합계
```regex
^-\s*(.+?)\s+매출:\s*([\d,]+)원
```
`re.MULTILINE` 옵션으로 각 줄의 시작에서 부스명을 찾고, `매출:` 바로 다음 금액만 추출합니다. 괄호 속 카드/현금 상세 금액과 쿠폰 금액을 제외합니다.

## 실제 로그 파일 실행 결과
- 유효한 이메일: **5개**
- 휴대전화 번호: **4개**
- 재학생 학번/학과: **3명**
- GitHub 저장소 URL: **3개**
- 2026년도 쿠폰 코드: **3개**
- 부스별 매출액: 타코야끼 푸드트럭 1,350,000원 / 불초밥 & 닭꼬치 부스 2,180,500원 / 수제 추로스 & 에이드 840,000원 / 공과대학 학생회 주점 1,920,000원
- **전체 매출 합계: 6,290,500원**

## 참고
정규표현식은 과제에서 제공된 로그의 형식에 맞춰 작성되었습니다. 모든 현실의 이메일 주소나 GitHub URL을 완전히 검증하는 범용 검사기는 아닙니다.
