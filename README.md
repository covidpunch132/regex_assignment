# 정규표현식 과제

파이썬의 `re` 모듈을 이용해서 전주대 대동제 및 해커톤 운영 로그에서 필요한 정보를 추출하는 프로그램입니다.

## 구현한 기능

1. **이메일 추출**  
   이메일 형식에 맞는 주소만 찾아서 출력합니다. `hyunwoo@.ac.kr`처럼 형식이 잘못된 주소는 제외했습니다.
2. **휴대전화 번호 추출**  
   `010`으로 시작하고 중간과 끝이 각각 4자리인 번호를 추출합니다. 하이픈, 점, 공백으로 구분된 번호도 찾을 수 있습니다.
3. **학번과 학과 추출**  
   대괄호 안에서 `202`로 시작하는 9자리 학번과 학과 이름을 함께 추출합니다.
4. **GitHub 주소와 쿠폰 코드 추출**  
   `github.com` 주소와 `FEST-2026-`으로 시작하는 쿠폰 코드만 추출합니다.
5. **부스별 매출 합산**  
   각 부스의 매출 금액을 찾아 더합니다. 카드·현금 세부 내역이나 쿠폰 금액은 중복으로 더하지 않습니다.

## 실행 방법

`main.py`와 `data.txt`를 같은 폴더에 두고 터미널에서 실행하면 됩니다.

```bash
python main.py
```

별도의 라이브러리 설치 없이 실행할 수 있습니다.

- 휴대전화 번호: 4개

- GitHub 주소: 3개 / 2026년 쿠폰 코드: 3개
